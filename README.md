# Job Search Agent

AI-powered job search pipeline: fetches live listings from Greenhouse, Lever and Ashby job boards, then scores and ranks them against a candidate profile using the Claude API.

## Status
Work in progress.

- [x] Fetch live jobs from Greenhouse job boards
- [x] Filter by job title keywords
- [ ] Support Lever and Ashby
- [ ] Score jobs for fit with the Claude API
- [ ] Draft tailored CVs and cover letters

## Tech
Python, Claude API
